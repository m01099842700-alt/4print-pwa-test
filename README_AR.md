# 4Print PWA — نسخة البداية للاختبار

هذه الملفات تجهّز واجهة PWA أولية لاختبار:
- واجهة عربية RTL متجاوبة.
- manifest.json.
- service-worker.js وتخزين ملفات الواجهة.
- أيقونة SVG.
- إرشادات التثبيت على الهاتف.

## تنبيه مهم
هذه ليست النسخة التشغيلية النهائية؛ لا تتصل بملف Google Sheets ولا تسجّل الطلبات أو المدفوعات. لا تستخدمها لإدارة الطلبات الحقيقية قبل إضافة طبقة الربط الآمنة واختبارها.

## رفعها إلى GitHub Pages
1. أنشئ مستودعًا جديدًا باسم `4print-pwa-test` واجعله Public (هذه الملفات لا تحتوي على بيانات أو كلمات مرور).
2. ارفع جميع الملفات مع الحفاظ على مجلد `icons`.
3. من Settings > Pages اختر Deploy from a branch.
4. اختر `main` و`/(root)` ثم Save.
5. انتظر ظهور رابط HTTPS وافتحه من الهاتف.

## الاختبار
- افتح رابط GitHub Pages.
- تأكد من ظهور الواجهة العربية.
- جرّب تثبيت التطبيق.
- افتح الصفحة بعد تثبيتها.
- افصل الإنترنت وافتح التطبيق: قد تظهر الواجهة المخزنة مؤقتًا، لكن لا توجد عمليات حجز أو سداد دون اتصال.

## قبل الربط الفعلي
يجب إعداد طبقة API آمنة بين GitHub Pages وGoogle Apps Script. لا تضع كلمة مرور الإدارة أو مفاتيح خاصة في ملفات الواجهة العامة.
